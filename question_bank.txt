STEM (EN): Which of the following is an official, recognized test objective according to the ISTQB syllabus?
STEM (SI): Which of the following is an official, recognized test objective according to the ISTQB syllabus? (ISTQB විෂය නිර්දේශයට අනුව පහත සඳහන් දෑ අතුරින් නිල වශයෙන් පිළිගත් පරීක්ෂණ අරමුණක් (test objective) වන්නේ කුමක්ද?)

OPTIONS:
  A) Proving that the software contains zero remaining defects.
  B) Diagnosing defect causes in the source code and removing them.
  C) Providing information to stakeholders to allow them to make informed decisions.
  D) Demonstrating that testing was performed exhaustively across all code paths.

>> CORRECT ANSWER: [C]

>> OFFICIAL RATIONALE:
Providing information to stakeholders for informed decisions is explicitly one of the 9 official test objectives (Section 1.1.1). Option A violates Principle 1 (testing shows presence, not absence of defects). Option B is debugging (a development activity). Option D violates Principle 2 (exhaustive testing is impossible).

QUESTION 2 of 71 [LO: FL-1.1.2 | Cognitive Level: K2]
--------------------------------------------------------------------------------
STEM (EN): How does dynamic testing fundamentally differ from debugging?
STEM (SI): How does dynamic testing fundamentally differ from debugging? (ගතික පරීක්ෂාව (Dynamic testing) සහ දෝෂ නිරාකරණය (Debugging) අතර ඇති මූලික වෙනස කුමක්ද?)

OPTIONS:
  A) Dynamic testing directly detects defects in code, whereas debugging reproduces failures.
  B) Dynamic testing triggers failures caused by defects, whereas debugging reproduces, diagnoses, and fixes the defects.
  C) Testing is performed exclusively by developers, whereas debugging is performed by independent testers.
  D) Testing eliminates defects from the software, whereas debugging measures statement coverage.

>> CORRECT ANSWER: [B]

>> OFFICIAL RATIONALE:
Dynamic testing executes software to trigger failures caused by defects. Debugging is the subsequent development process: (1) reproduction of failure, (2) diagnosis (finding the defect), and (3) fixing the defect (Section 1.1.2).

What are the ERROR, DEFECT, and FAILURE in this scenario? OPTIONS:
  A) Error: Mistyping the operator; Defect: Flawed code in algorithm; Failure: System crash at checkout.
  B) Error: Overtime fatigue; Defect: System crash; Failure: Mistyped operator.
  C) Error: System crash; Defect: Mistyping the operator; Failure: Customer complaint.
  D) Error: Flawed code; Defect: Mistyped operator; Failure: Customer purchases goods.

>> CORRECT ANSWER: [A]

>> OFFICIAL RATIONALE:
The human mistake of mistyping the operator is the Error . The resulting flaw in the source code is the Defect . The observable system crash during execution is the Failure . (Overtime fatigue is a root cause) (Section 1.2.3).

QUESTION 10 of 71 [LO: FL-1.2.2 | Cognitive Level: K1]
--------------------------------------------------------------------------------
STEM (EN): What is the relation between testing and quality assurance (QA)?
STEM (SI): What is the relation between testing and quality assurance (QA)? (පරීක්ෂාව (testing) සහ තත්ත්ව සහතිකකරණය (Quality Assurance - QA) අතර සම්බන්ධය නිවැරදිව දක්වන්නේ කුමක්ද?)

OPTIONS:
  A) Testing and QA are the same activity; both are product-oriented and corrective.
  B) QA is a product-oriented activity that is performed only after testing has finished.
  C) Testing is a form of quality control (product-oriented, corrective) that supports quality assurance, which is process-oriented and preventive.
  D) QA applies only to testers, while developers are responsible for quality control only.

>> CORRECT ANSWER: [C]

>> OFFICIAL RATIONALE:
Quality management includes QA and QC. QA is a process-oriented, preventive approach focused on implementing and improving processes. QC is a product-oriented, corrective approach, and testing is a major form of QC. Test results are used in QC to fix defects and in QA as feedback on how well the development and test processes perform (Section 1.2.2).

  D) Only the tools change; plans, techniques and criteria remain unchanged.

>> CORRECT ANSWER: [C]

A regulated safety-critical project therefore needs more rigor.
